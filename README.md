# 🌅 Bing Image of the Day

A minimal Chrome extension that displays Bing’s *Image of the Day* without any Bing UI elements — just the beautiful background itself.

---

## ✨ Features

- 🖼️ **Clean View** – Shows Bing background image only (no logo, no search box, no distractions).  
- 🔁 **Auto Refresh** – Updates automatically every 5 minutes with the latest Bing image.  
- 🧭 **Fullscreen Mode** – Double-click anywhere to toggle fullscreen view.  
- ⚡ **Manifest V3** – Built using the latest Chrome Extension standard.

---

## 🛠️ Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/Abiddarris/Bing-Image-Of-The-Day.git
   ```
2. Open Chrome and go to:
   ```
   chrome://extensions
   ```
3. Enable **Developer Mode** (top-right corner).
4. Click **Load unpacked** and select the project folder.

---

## 🚀 Usage

* Open the extension’s page to view Bing’s *Image of the Day*.
* The image refreshes automatically every **5 hours**.
* **Double-click** anywhere to enter or exit fullscreen mode.
